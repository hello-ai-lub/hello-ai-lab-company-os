PRODUCT LINEART PREVIEW

WEB用商品線画の試作確認

試作対象は、正面1点の共通ルールで描き直した4商品です。参考線画は形状確認のみに使用し、小表示でも認識しやすい太さ・余白・配置に統一しています。ディテール線画は仕様確認が必要な要素だけを抽出しています。

01 / TANK TOP

TANK TOP

肩幅を細くしすぎず、ネックとアームホールのバインダーだけを残した、視認性優先の正面線画です。

  • 特徴保持: ラウンドネック、深めのアームホール、緩いラウンドヘム
  • 簡略化: 縫い目のノイズと不要なシワ線は削減
DETAIL / BINDING

ネックの開きとバインダー幅の確認用。

DETAIL / HEM

前裾のラウンド感だけを残した簡略ディテール。

14 / LONG PANTS

SWEAT LONG PANTS

裾リブが強いジョガーではなく、WEB上で脚のシルエットが読み取りやすいストレート寄りのロングパンツとして整理しています。

  • 特徴保持: ゴムウエスト、サイドポケット、ストレートの落ち感
  • 簡略化: ギャザーと皺は最少本数へ圧縮
DETAIL / WAIST + POCKET

ウエスト仕様とポケット角度の確認用。

DETAIL / HEM

裾の処理を小サイズでも読み取れる太さで整理。

16 / PULLOVER HOODIE

PULLOVER HOODIE

フード、袖口リブ、裾リブを残しつつ、WEB用として外形を先に読ませる描き方に寄せた試作です。

  • 特徴保持: フード、リブ袖口、リブ裾
  • 判断保留: ポケットは商品仕様に明記がないため追加していません
DETAIL / HOOD

フード開きと前重なりの確認用。

DETAIL / RIB

袖口と裾のリブ密度を共通ルールで確認。

18 / WINDBREAKER JACKET

WINDBREAKER JACKET

立ち襟、フルZIP、サイドポケット、裾ドローコードを優先して読み取れるよう整理したWEB用試作です。

  • 特徴保持: 立ち襟、ZIP、ポケット、裾ドローコード
  • 簡略化: シワ線と袖の分量は最小限に整理
DETAIL / COLLAR + ZIP

立ち襟とZIPの見え方確認用。

DETAIL / POCKET + HEM

ポケット開口と裾ドローコードの確認用。
