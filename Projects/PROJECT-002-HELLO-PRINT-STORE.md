## 📋 PROJECT OVERVIEW

### Mission
Hello Print Storeをブランドサイト化し、「福岡で一番ブランド力のあるオーダーウェアメーカー」へ進化させる。

**重要**: ホームページ完成 ≠ プロジェクト成功  
**真の目標**: ブランド体験の設計と実装

### Core Concept
```
Design for Teams.
Create for Culture.

Helloは「ユニフォームを売る会社」ではなく、
「ブランドやチームの世界観を一緒に作る会社」
```

### Design Philosophy
```
【参考ブランド】
Nike（ミニマル × ブランド力）
KITH（プレミアム × コミュニティ）
Friends ONLY（カルチャー感 × コミュニティ × 自然さ）

【最重要】
Friends ONLY が参考になる理由：
  • 服だけではなくカルチャーを感じる
  • 仲間やコミュニティの空気がある
  • 作り込みすぎていない自然さ
  • 少しストリート感がある
  • 写真の並びや見せ方に遊びがある
  • ブランドを説明しすぎない
  • 見る側に世界観を感じさせる
  • 商品販売だけで終わらない
  • 閉じた仲間感と特別感がある

【デザイン判断の優先順位】
1. Helloらしいか（最優先）
2. Friends ONLYのようなカルチャー感があるか
3. 写真が主役になっているか
4. オーダーしたくなる空気があるか
5. Nike・KITHのような洗練があるか

【重要な選択】
Nike・KITHの洗練よりも、
Friends ONLYの自然なカルチャー感とコミュニティ感を優先する

【制作時に常に問い直すこと】
  ❓ これは普通の印刷会社に見えていないか
  ❓ 綺麗にまとめすぎていないか
  ❓ 商品カタログになっていないか
  ❓ Helloの仲間感が出ているか
  ❓ 写真から空気感が伝わるか
  ❓ Friends ONLYが作るなら、もっとどう崩すか
  ❓ Helloだったら、どう表現するか

【最終目標】
「商品を見るサイト」ではなく
「Helloの世界に入りたくなるサイト」を作ること
```

## 🎯 PHASE 1: ブランド設計

**期間**: 2026-08-03 ～ 2026-08-05  
**目標**: Helloらしい世界観を言語化・可視化する

### 1.1 デザインシステム定義

#### カラーシステム

```
【Primary】
- White（背景）：#FFFFFF
- Black（テキスト）：#000000

【Accent】
- Hello Orange：#FF7B3D（すべてのアクセント・CTA）

【Secondary】
- Light Gray：#F5F5F5（背景変化）
- Medium Gray：#999999（補助テキスト）
- Dark Gray：#333333（標準テキスト）

【ルール】
- アクセントカラーはHello Orangeのみ
- 白黒ベースで余白と高級感を表現
- 色数を極力抑える（5色以下）
```

#### タイポグラフィ

```
【Font Family】
- Heading：SFProDisplay / Inter（モダン、高級感）
- Body：SFProText / Inter（読みやすさ）

【Font Scale】
H1: 56px / 48px (SP)
H2: 40px / 32px (SP)
H3: 28px / 24px (SP)
H4: 20px / 18px (SP)
Body: 16px / 14px (SP)
Caption: 12px / 11px (SP)

【ルール】
- 文字は少なく
- 余白を活用して高級感を演出
- 行間：1.6～1.8（読みやすさ）
```

#### スペーシング

```
Base unit: 8px

xs: 8px
sm: 16px
md: 24px
lg: 32px
xl: 48px
xxl: 64px

【ルール】
- 余白を多く使う
- セクション間隔：xxl以上
- 要素間隔：lg以上
- 高級感 = 余白の豊富さ
```

#### グリッドシステム

```
【デスクトップ】
- 12列グリッド
- カラム幅：1/12
- ガター：24px

【タブレット】
- 8列グリッド

【スマートフォン】
- 4列グリッド
```

#### Imagery Style

```
【TOP ファーストビュー - 世界観写真】
- 構成：複数の商品がランダムに重なった配置
- 被写体：ユニフォーム＋Tシャツ＋スポーツウェア＋オリジナル商品
- スタイル：自然で無造作、但し計算された構図
- 色彩：Helloらしい色彩バランス
- 目的：「ブランドの空気感」を伝える
- ロゴ配置：写真上の中央付近、控えめなサイズ（重要：目立たない）

【その他セクション - 写真の扱い】
- 大きく（セクション高さ：60-80vh）
- 最小加工（Helloらしさを損なわない）
- 被写体：ユニフォーム・制作風景・着用シーン・オリジナル商品
- 色：カラーバランスを白黒背景に合わせる

【ロゴの位置付け】
- TOP：世界観写真に自然に存在する
- その他ページ：ナビゲーションやヘッダーの一部
- 原則：ロゴを押し付けない、「そこにある」感覚

【アニメーション】
- Entrance animation: fade in, subtle slide
- Scroll animation: 上品に、控えめに
- CTA animation: Hoverで目立つが邪魔にならない
- Transition: 300-400ms（快適さ）

【ホワイトスペース】
- 背景に負の空間を作る
- 余白を使って注目度を上げる
- 写真と文字の間隔：lg以上
- TOP：世界観写真が主役を邪魔しない余白配置
```

### 1.2 トーンアンドマナー

#### Voice & Tone

```
【Brand Voice】
- Modern（モダン）
- Premium（プレミアム）
- Collaborative（協業的）
- Authentic（本物感）

【Tone】
- 堅くない（カジュアルでない）
- 上から目線でない
- チーム・コミュニティを感じさせる
- 作り込みすぎない自然感

【Examples】
❌「世界最高級のユニフォーム」
✅「チームの世界観を形にする」

❌「当社の製造技術は優秀です」
✅「制作するとき、大切にしていること」
```

#### Copywriting Guidelines

```
【原則】
- 1行20文字以下
- 短く、明確に
- 写真が主役なので文字は補助
- 説明的にならない

【例】

❌ 長い説明文
「Hello Print Storeではお客様のブランドやチームの世界観を
理解した上で、最高品質のユニフォームをカスタマイズして
製作いたします。」

✅ 短く、Helloらしく
「チームの世界観を、
一緒に作る。」

【セクションごとのコピー】
- TOP: 1-2行（写真がメイン）
- WORKS: タイトル + 短い説明
- FLOW: ステップ名のみ
- ITEMS: 商品名 + 1行説明
- ORIGINALS: 1-2行コンセプト
- ABOUT: 3-4行のストーリー
```

### 1.3 デザイン参考

#### 参考にすること

```
Nike
→ ミニマルな美しさ
→ 強烈なブランド世界観
→ 写真を最大限活用

KITH
→ プレミアム感

→ ビジュアルの高質化

Friends ONLY
→ カルチャー感

#### 参考にしないこと

```

❌ アニメーションの真似
```

#### Helloオリジナリティの軸

```
Helloは「福岡」「オーダーメイド」「ブランド＝文化」

この3要素を写真・デザイン・コピーで一貫表現する
```

```

【実装】
- レスポンシブグリッド
- タッチフレンドリーなCTA
- 縦方向の流れを自然に
- 写真はスマホに最適化

【ルール】

- スマホ ⊇ デスクトップ ではなく
- スマホ最適 ← → デスクトップ最適

## � Phase 2（ワイヤーフレーム）への戦略的指示

### Friends ONLY スタイル統合ガイド

```
【ワイヤーフレーム作成時の最重要ポイント】

1. 写真が主役
   - 各セクションで大きな写真エリアを確保
   - テキストは最小限
   - 写真と余白のバランスを最優先

2. カルチャー感・コミュニティ感の表現
   - 「商品カタログ」ではなく「世界観への入口」
   - ユーザーが「仲間になりたい」と感じる導線設計
   - 説明的なテキストは避ける

3. 無造作さの設計
   - 整列しすぎない配置
   - グリッドの「遊び」を設計に組み込む
   - Friends ONLY のような自然なランダム感

4. スクロール体験
   - 段階的に世界観が明かされる流れ
   - 写真からブランドイメージが伝わる順序
   - CTAは自然な流れの中に配置

【ワイヤーフレーム検証チェック】

☑ 写真が主役になっているか（テキストが邪魔していないか）
☑ 商品説明ページになっていないか（ブランドページになっているか）
☑ Helloの仲間感が感じられるか
☑ 「普通の印刷会社」に見えていないか
☑ Friends ONLY のような空気感があるか
☑ スマホでの見え方は自然か
☑ 各ページの導線は世界観を損なわないか
```

### 各ページのワイヤーフレーム設計指針

```
【TOP】
- 背景：ユニフォーム・Tシャツ・オリジナルウェアが無造作に重なった写真
- ロゴ：控えめなサイズで自然に配置
- CTA：最小限（VIEW WORKS / START YOUR ORDER）
- 意図：「Hello の世界観」を3秒で感じさせる

【WORKS】
- ポートフォリオ一覧
- Instagram的な「グリッドとランダムな配置」の融合
- 各作品から「カルチャー」が伝わるサムネイル
- フィルター機能（カテゴリ別）

【FLOW（5ステップ）】

【ITEMS】

【HPS ORIGINALS】
- オリジナル商品専用の「特別感」を表現

- 限定感・カルチャー感を演出

【ABOUT】
- 「Hello という存在」を語る
- 写真 >> テキスト
- 福岡の地域性 + Helloらしさ

【CONTACT】
- シンプル
- 行動喚起（オーダーへ導く）
```
