## 🎯 TOP ファーストビュー - 詳細設計（修正版）

### デザイン方針（REVISED）

```
【主役】
"Hello Print Storeという世界観"
（ヒーロー画像ではなく、ブランドの空気感）

【デザイン意図】
- 写真が世界観を作る
- ロゴはブランドを伝える
- ロゴは「自然にそこにある」程度の存在感
- 写真・ロゴ・余白のバランスを最優先
- "印刷会社" ではなく "ブランド" として認識させる

【期待される感情反応】
「なんかカッコいい」
「このブランド好き」
「ここに頼みたい」
```

### ファーストビューの構成

```
【背景写真 - 世界観ビジュアル】

複数の商品がランダムに重なっている写真
（自然な無造作感 = 計算された構図）

構成要素：
  • オリジナル商品（最優先で見える）
  • ユニフォーム各種（複数アングル）
  • Tシャツ・長袖・ショーツ
  • スポーツウェア

配置パターン：
  ├─ 左上：オリジナル商品の一部がチラ見え
  ├─ 中央：複数商品が重なったメインビジュアル
  ├─ 右下：別の商品がランダムに
  └─ 全体：「自然」と「計算」の融合

【ロゴ配置】

位置：写真上の中央やや上
サイズ：全画面幅の 20-30%（控えめ）
存在感：「自然にそこにある」状態
効果：デジタルと物理の融合を表現

※ロゴは大きくない。ブランドを押し付けない。

【テキスト配置】

コピー：
「Design for Teams.
 Create for Culture.」

位置：ロゴ下、中央配置
サイズ：H2（40px / 32px）
配置：ロゴとの余白を最優先

【CTA配置】

ボタン1：VIEW WORKS
  └─ White背景 / Black Border

ボタン2：START YOUR ORDER
  └─ Hello Orange背景 / White テキスト

位置：テキストの下、中央配置
形式：横並び（デスクトップ）/ 縦積み（スマートフォン）
サイズ：大きすぎない、バランスを重視

【スクロールハント】

下部：「↓ Scroll」などの微かなハイント
位置：CTA下、フェードイン表現
目的：スクロールを促す（邪魔にならない範囲で）
```

### 全高・スペーシング

```
【デスクトップ】
全高：100vh（フルスクリーン）
理由：最高の没入感を実現

【スマートフォン】
全高：80-90vh
理由：下部にスクロールハント・次セクションをチラ見せ

【内部スペーシング】
ロゴ → コピー間：lg（32px）
コピー → CTA間：lg（32px）
CTA → スクロールハント間：md（24px）
```

### カラー・透明度

```
【背景写真】
- カラー撮影（Helloの色彩が活きる）
- オーバーレイ：必要に応じて薄く（0-10%）
  （テキスト読みやすさを損なわない範囲）

【ロゴ】
- 色：White or Black（写真とのコントラスト最適化）
- 半透明：不可（存在感を保つ）

【テキスト】
- 色：White or Black（読みやすさ最優先）
- 対比度：WCAG AA 以上を満たす

【背景グラデーション】
- 使用：選択的（写真の美しさを損なわない場合のみ）
- 方向：下方向への薄いグラデーション（余白感UP）
```

### スクロール・アニメーション

```
【ページロード時】
背景写真：フェードイン（0.8s easeOut）
ロゴ：フェードイン + 微かなスライドアップ（0.8s 0.2s遅延）
テキスト：フェードイン（0.8s 0.4s遅延）
CTA：フェードイン（0.8s 0.6s遅延）

【スクロール動作】
背景写真：静止（Parallax効果なし、シンプルさを重視）
フェード：下方向スクロールで透明度↓（0.2 → 0.5）
テキスト：ゆっくりフェードアウト
CTA：控えめなスライドアップ（10-20px）

【CTA Hover（デスクトップ）】
VIEW WORKS：Hello Orange のボーダーハイライト
START YOUR ORDER：背景色 Hover（より濃いオレンジ）
効果：期間 200-300ms（快適）

【スクロールハント】
微かなバウンス（↓が上下に振動）
アニメーション期間：1-2s
ループ：無限（ユーザーがスクロールまで）
消失：ユーザーがスクロールを開始したら自動的にフェードアウト
```

### スマートフォン対応

```
【背景写真】
縦向き最適化（UXを損なわない）
アスペクト比：3:4 推奨

【ロゴ】
サイズ：20-30% 維持（さらに控えめな場合あり）
重要：タップ不可（リンク機能なし）

【テキスト】
H2 → H3 への縮小可（読みやすさを損なわない範囲）
フォントサイズ：32px → 24px

【CTA】
形式：縦積み（各ボタンが画面幅の80-90%）
タップサイズ：最小 48px × 48px 確保
間隔：md（24px）

【スクロールハント】
位置：画面下部
サイズ：さらに小さく（モバイル画面に合わせる）
可視性：はっきり見える（対比度 WCAG AA以上）

【全高】
スクロールハントが見える範囲で調整
通常 80-90vh でCTAが画面内に収まる
```

### 実装ポイント

```
【WordPress/Elementor対応】
- Full Width Section で背景画像設定
- Elementor Column + Inner Section の活用
- Custom CSS でアニメーション実装

【必要な Custom Code】
JavaScript：
  • スクロール検出 → スクロールハント消失
  • ロゴの段階的表示
  • CTA Hover エフェクト

CSS：
  • アニメーション（@keyframes）
  • レスポンシブ対応
  • Z-index 管理
  • Transparency 制御

【画像管理】
- ファイル名：`top-hero-world-01.jpg` など
- サイズ：最小 1920px × 1080px（デスクトップ）
-  最小 1080px × 1440px（スマートフォン）
- 形式：WebP + JPG フォールバック
- 最適化：80% 圧縮でも高品質
```
