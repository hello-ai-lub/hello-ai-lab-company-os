## 📋 TEMPLATE INSTRUCTION

このテンプレートを使用する際は、以下の3つのみを入力してください：

```
【ANIMAL】 = 動物の名前と基本情報
【LEARNING_FACT】 = 1つの豆知識（子どもでも理解できる簡潔な事実）
【STORY_HOOK】 = 冒頭2秒で視聴者を引き込む特徴的な瞬間
```

残りすべての内容は固定です。
