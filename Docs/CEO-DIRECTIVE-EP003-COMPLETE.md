## ✅ 新制作ルール確定

### Episode004以降

**最優先テーマ**

```
「映像だけで雑学が少し伝わる演出」
を必ず1つ以上入れる
```

### 具体的な実装方法

#### 方法①：他の動物との比較
```
例：カピバラ × ハツカネズミ
→ サイズ比較で「世界最大のネズミ」が可視化
```

#### 方法②：リアクション
```
例：オッターが手をつなぐ
→ 「つなぐ理由 = 流されないため」が行動で表現
```

#### 方法③：小物の活用
```
例：ペンギンが石を使う
→ 「ペンギンは工具を使う」が一目瞭然
```

#### 方法④：ストーリー展開
```
例：ライオンの親子
→ 狩りを教える場面
→ 「親が子に狩りを教える」が描写で伝わる
```

#### 方法⑤：背景演出
```
例：キツネの耳が立つ
→ 「耳がいい」という特徴が姿勢で表現
```

### 実装の優先順位

```
【最高優先】
他の動物との比較
リアクション

【高優先】
小物の活用

【中優先】
ストーリー展開
背景演出
```
